### Безопасность GitHub Actions:
- **КАТЕГОРИЧЕСКИЙ ЗАПРЕТ:** Торговый seed или приватный ключ Solana **НИКОГДА** не передается в GitHub Actions.
- В секретах репозитория хранятся **ТОЛЬКО** ключи разработчика для цифровой подписи APK (`RELEASE_KEYSTORE_BASE64`).
- Торговый ключ вводится **ТОЛЬКО** оператором внутри установленного на телефоне приложения и шифруется чипом устройства.

## 3. Четыре роли рантайма (Без участия чатов)

| Роль | Место выполнения | Ответственность | Взаимодействие |
|---|---|---|---|
| **1. Оператор («Вайб-кодер»)** | Экран смартфона | Держит телефон, пополняет микро-депозит (0.05 SOL), нажимает 3 кнопки (▶/⏸/⛔) или тумблер Автопилота, считывает понятные карточки. | 0 текста промптов, 0 терминалов. Только тапы по кнопкам. |
| **2. Локальное Ядро (Engine)** | Фоновый сервис на телефоне | 24/7 сканирует Raydium/Pump.fun по gRPC/RPC, открывает максимум 1 сделку, держит трейлинг-стоп, отправляет Jito-бандлы. | Полная математическая автономия. Не требует подтверждения для штатных выходов. |
| **3. Планировщик эволюции** | Локальная фоновая задача | Анализирует сделки, тестирует параметры на истории, безопасно двигает коридоры (±10%), при деградации делает авто-откат. | Риск-нейтральные улучшения применяет сам; при повышении риска шлет пуш «Нужна ты». |
| **4. Советник Gemini (Cold)** | Локальный вызов по API-ключу | Оценивает вирусность мемов и кластеры кошельков разработчиков. | Работает в режиме «Только совет». Не имеет доступа к кошельку и не может увеличить риск. |

## 4. Ритуал оператора из 5 шагов (Главный экран)

1. **Пополни микро-депозит:** переведи от 0.05 до 0.5 SOL на адрес локального торгового кошелька.
2. **Проверь чек-лист:** убедись, что все 16 индикаторов готовности (Preflight) горят зелёным.
3. **Включи Док-режим:** поставь телефон на зарядку на подставку с активным экраном на ночь.
4. **Нажми «Автопилот»:** робот возьмет управление на себя в режиме 24/7.
5. **Иди спать:** если возникнет нестандартная ситуация, приложение пришлет громкое локальное уведомление **«Нужна ты»** с двумя кнопками: `[ОДОБРИТЬ]` или `[ОТКЛОНИТЬ]`.

## 5. Каталог экранов мобильного пульта (17 разделов)

1. `home` — Главный пульт: Светофор состояния, большой тумблер Автопилота, баланс, 3 кнопки аварийного контроля (▶ Пуск / ⏸ Пауза / ⛔ Стоп), карточки «Нужна ты».
2. `analytics` — Аналитика и PnL: Сверка факта с симуляцией (черный ящик), скользящая доходность, винрейт, распределение проскальзывания.
3. `risk` — Катастрофические рубежи: Лимит на сделку (0.04 SOL), дневной стоп-лосс (-0.10 SOL), авто-вывод прибыли (Sweep) на публичный холодный адрес сейфа.
4. `wallets` — Хранилище ключей: Маскированный ввод торгового seed-а, индикатор шифрования Android Keystore StrongBox, биометрия, кнопка безвозвратного стирания ключа.
5. `transactions` — Трекер посылок: 6-фазная цепочка (`ЗАГОТОВЛЕНА` ➔ `ОТПРАВЛЕНА` ➔ `В БЛОКЕ` ➔ `ИСПОЛНЕНИЕ` ➔ `ПОДТВЕРЖДЕНИЕ` ➔ `ДЕЙСТВИЕ`).
6. `strategy` — Настройка стратегии: Скорость фиксации прибыли, порог жадности, динамические коридоры авто-подстройки.
7. `gas` — Газ и Jito: Настройка чаевых валидаторам (Эконом / Быстрый / Турбо / Ультра), лимиты расходов на транзакции.
8. `market` — Радар мемкоинов: Живой поток токенов с bonding curves Pump.fun и Raydium, фильтры ликвидности.
9. `smart_money` — Умные деньги: Радар инсайдеров и снайперов с детекцией кошельков создателей.
10. `trends` — Тренды соцсетей: Вирусные темы и тональность мем-нарративов.
11. `history` — Журнал сделок: История закрытых позиций с записью в постоянный журнал.
12. `selftest` — Самопроверка и стрессы: Симуляция обрыва сети, просадки батареи, дампа разработчика.
13. `network` — Режимы и безопасность: Переключение Симуляция / Боевой микро, памятка о защите ключей от утечки в GitHub.
14. `help` — Инструкция оператора: Памятка по безопасности, 5-шаговый ритуал, честное сравнение Док-режима и карманного режима.
15. `micro_live` — Боевой-микро надзор (Этап 24): Аудит 5 контрольных микро-сделок, подтверждение работы с реальным RPC.
16. `scaling` — Масштабирование капитала (Этап 25): Правило шага не более чем в 2 раза (<=2x), канареечный прогон, журнал решений.
17. `handsoff` — Автономия «Под ключ» (Этапы 26–27): Сводка 24-часового непрерывного цикла, 8 автоматических проверок, суточный push-дайджест.

## 6. Защитные инварианты, которые невозможно обойти

- **Инвариант 1 позиции:** Робот никогда не открывает вторую сделку, пока первая не закрыта полностью.
- **Жёсткий тайм-аут удержания:** Максимум 180 секунд на сделку; никаких многочасовых пересиживаний убытков.
- **Однокнопочный Kill-Switch:** Мгновенно блокирует все новые входы и принудительно распродает остатки по рынку.
- **Изоляция торгового ключа:** Приватный seed никогда не покидает чип смартфона, не выводится в логи, не отправляется на серверы и не виден в DOM-дереве.
- **Авто-свип прибыли:** При накоплении профита излишки автоматически перечисляются на публичный холодный адрес сейфа.
