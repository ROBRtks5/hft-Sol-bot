## 4. Оставшиеся известные риски и митигации

1. **Троттлинг сетевого модема в кармане (Doze Mode):** Android при длительном выключенном экране пакетирует соединения.  
   *Митигация:* Использовать Док-режим (телефон на зарядке с включённым экраном) для ночной охоты за memecoin-пампами.
2. **Экстремальный скачок комиссий в сети Solana (> 0.01 SOL/tx):**  
   *Митигация:* Встроенный жесткий потолок Jito Tip Governor отменяет отправку при превышении бюджета.
3. **Мгновенный дамп разработчика в том же слоте (Same-Slot Dev Rug):**  
   *Митигация:* Детектор неблагоприятного отбора мгновенно сбрасывает позицию в рынок при первой крупной продаже в пуле.
4. **Правило масштабирования капитала:**  
   *Митигация:* Увеличение экспозиции строго не более чем в 2 раза (<=2x) за один шаг и только с ручного подтверждения оператора на экране телефона.
